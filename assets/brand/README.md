# Identidade Grupo J — Auto App

Artes oficiais fornecidas pelo responsável pelo projeto em 22/09/2026, preservadas sem redesenho.

- `grupo-j-horizontal.png`: assinatura completa, aplicada sobre azul-marinho para preservar a leitura de AUTO APP.
- `grupo-j-profile.png`: símbolo para ícones, abertura e aplicações compactas.

Execute `node scripts/prepare-brand-assets.cjs` na raiz para atualizar as cópias dos portais e os tamanhos exigidos pelo aplicativo e pelo Android. Preserve a proporção original; não recolora a arte.

A identidade foi incorporada ao APK 0.2.4 (código 6), aos painéis administrativo e de oficinas e aos ícones instaláveis. A alteração do ícone Android exige instalar o APK atualizado. Evidência de integridade das artes no pacote: `artifacts/brand-verification.json`.
